### 4.2.1.2. Aspect Leaders and Collaborators

En el presente Sprint 1, el alcance funcional y técnico del ecosistema **ShiftIQ** abarca la presencia web comercial (Landing Page), la plataforma backend de servicios RESTful (`shiftiq-platform`) y la inicialización de la aplicación móvil (`shiftiq-mobile-app`). Para garantizar un desarrollo ordenado y especializado por parte del equipo TuxLogic, las actividades se dividieron en cinco aspectos principales:

1. **Landing Page (Frontend Web):** Liderado por **Mallqui Vilca, Dhilsen Armil**, abarca el desarrollo de la interfaz gráfica comercial, maquetación semántica HTML5/CSS3, componentes interactivos y diseño responsive en el repositorio [Shiftiq-Landing-Page](https://github.com/tux-logic/Shiftiq-Landing-Page).
2. **Backend REST API Platform (Spring Boot / Java):** Liderado conjuntamente por **Machacca Soto, Aldo Jeanfranco** y **Mamani Vilca, Alan Jaivi**, abarca la implementación de microservicios backend basados en Tactical DDD (IAM, Core, Operations, Fleet, IoT y Billing) en el repositorio [shiftiq-platform](https://github.com/tux-logic/shiftiq-platform).
3. **Architecture & Database (PostgreSQL / DDD / C4):** Liderado por **Machacca Soto, Aldo Jeanfranco** y **Mamani Vilca, Alan Jaivi**, abarca el diseño del modelo relacional en PostgreSQL 18, mapeo de entidades JPA y diagramación C4.
4. **Mobile Application (Flutter / Dart / Android):** Liderado por **Mamani Vilca, Alan Jaivi** y **Vidal Malaga, Jareth Beycker**, abarca la arquitectura base, setup de dependencias y pantallas clave de la aplicación móvil en el repositorio [shiftiq-mobile-app](https://github.com/tux-logic/shiftiq-mobile-app).
5. **DevOps, QA & Deployment:** Liderado por **Ramos Hinostroza, Diego Antonio** con el soporte de **Mallqui Vilca, Dhilsen Armil**, comprende la configuración de GitHub Actions CI/CD, contenedorización con Docker / Docker-Compose y suites de pruebas JUnit 5.
