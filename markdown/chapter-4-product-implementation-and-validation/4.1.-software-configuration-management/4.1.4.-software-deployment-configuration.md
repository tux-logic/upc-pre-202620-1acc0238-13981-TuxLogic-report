# 4.1. Software Configuration Management

## 4.1.4. Software Deployment Configuration

ShiftIQ publica cada producto en el destino que le corresponde. La landing es un sitio estático. La API es un contenedor Java que habla con PostgreSQL y con los servicios externos del diagrama de despliegue.

### Landing page

El repositorio [Shiftiq-Landing-Page](https://github.com/tux-logic/Shiftiq-Landing-Page) se despliega en [Vercel](https://vercel.com/). `vercel.json` declara un sitio estático: sin framework de compilación, con la raíz del repositorio como directorio de salida y con URLs limpias. Cada integración en `main` publica esa raíz.

### Plataforma backend

La API se empaqueta con el Dockerfile del repositorio [shiftiq-platform](https://github.com/tux-logic/shiftiq-platform).

1. La etapa de construcción usa Maven 3.9 sobre Eclipse Temurin 26 y genera el JAR con `./mvnw clean package`.
2. La etapa de ejecución usa el JRE 26, activa el perfil `prod` y escucha en el puerto 8080.

En producción la conexión a PostgreSQL exige SSL. El perfil `prod` arma la URL JDBC con `DATABASE_URL`, `DATABASE_PORT`, `DATABASE_NAME`, `DATABASE_USER` y `DATABASE_PASSWORD`. También hacen falta, como variables de entorno y no como valores en el código, `JWT_SECRET`, las credenciales de correo, `GOOGLE_CLIENT_ID`, las claves de Stripe y las de Factos.

El esquema de base de datos lo administra Hibernate a partir de las entidades JPA. Los nombres físicos de tabla los define la estrategia snake_case en plural del contexto `shared`.

### Servicios externos

Según el diagrama de despliegue, la API en ejecución se conecta con tres servicios que ya están configurados en la plataforma:

* **Correo:** SMTP para notificaciones y comprobantes.
* **Stripe:** cobro de los planes del taller.
* **Factos:** emisión de comprobantes electrónicos ante SUNAT.

### Aplicación móvil

La aplicación Android en Kotlin se distribuye como paquete de la propia app cuando exista su repositorio de implementación. En esta configuración el canal ya definido y publicado es la landing en Vercel y la API en contenedor.
