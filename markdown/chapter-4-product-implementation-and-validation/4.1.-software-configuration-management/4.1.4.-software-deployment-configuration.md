# 4.1. Software Configuration Management

## 4.1.4. Software Deployment Configuration

### Continuous Integration & Deployment (CI/CD)
- **Web Landing Page:** Continuous Deployment to **Vercel** on every push to `main`.
- **Backend REST Microservices:** GitHub Actions CI workflow for Maven build & unit testing, followed by deployment to cloud container platforms (Render / AWS ECS).

### Database Migrations
- Managed via **Flyway Database Migrations** (`src/main/resources/db/migration/V1__init_schema.sql`).
