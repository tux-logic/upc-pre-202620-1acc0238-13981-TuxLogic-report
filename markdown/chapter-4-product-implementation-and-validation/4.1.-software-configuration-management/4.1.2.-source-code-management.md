# 4.1. Software Configuration Management

## 4.1.2. Source Code Management

### Version Control Platform
The project source code and report documentation are managed in GitHub under the organization repository `TuxLogic/ShiftIQ`.

### Git Branching Model (GitFlow)
- **`main`:** Production-ready release branch.
- **`develop`:** Active integration branch.
- **`feature/*`:** Feature branches for individual user stories (e.g., `feature/us01-landing-page`).
- **`docs/*`:** Documentation refinement branches (e.g., `docs/restructure-documentation`).

### Pull Request & Review Policies
- All code additions require a Pull Request targeting `develop`.
- Minimum 1 approved code review required.
- Automated CI build and linting checks must pass prior to merging.
