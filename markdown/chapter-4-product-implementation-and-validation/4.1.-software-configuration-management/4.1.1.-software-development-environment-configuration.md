# 4.1. Software Configuration Management

## 4.1.1. Software Development Environment Configuration

### Backend Stack & Dependencies
- **Programming Language:** Java 21 LTS
- **Framework:** Spring Boot 3.x (Spring Web, Spring Data JPA, Spring Security)
- **Database:** PostgreSQL 16 (Relational DB) & Redis (In-Memory Cache)
- **Build Tool:** Apache Maven 3.9

### Web Frontend Stack
- **Environment:** Node.js v20 LTS
- **Framework:** React 18 / Next.js 14 (App Router)
- **Styling:** Vanilla CSS & TailwindCSS

### Mobile Companion App Stack
- **Framework:** Flutter 3.x / Dart 3.x
- **Target OS:** Android (API Level 34) & iOS (iOS 17+)

### Containerization & Local Infrastructure
- **Docker Engine & Docker Compose:** Standardized `docker-compose.yml` for local PostgreSQL and Redis instances.
