# 3.1. Product design

## 3.1.1. Style Guidelines

### 3.1.1.1. General Style Guidelines

Las decisiones generales de estilo se basan en los valores de marca de ShiftIq: confianza, transparencia, profesionalismo técnico y claridad diagnóstica aplicada al sector automotriz.

**Branding y tono de comunicación**
- Tono: Profesional, claro y orientado a la acción preventiva. Se evita el lenguaje técnico excesivo hacia el conductor (se traduce el código DTC a lenguaje natural), pero se mantiene precisión y rigor en el panel operativo del taller.
- Personalidad de marca: Confiable, técnica, transparente y proactiva.
- Valores visuales: Claridad en la jerarquía de severidad (Bajo/Medio/Crítico), orden operativo y sensación de control sobre el estado del vehículo.

**Tipografía**
Sistema basado en dos familias con escala tipográfica coherente (Base: 16px, Scale: 1.25):
- Heading (títulos): Poppins (Semi-Bold/Bold) — h1: 61px, h2: 49px, h3: 39px, h4: 31px, h5: 25px.
- Body (texto): Inter (Regular/Medium) — para máxima legibilidad de datos técnicos y alertas en pantallas móviles.

**Espaciado e iconografía**
- Sistema de espaciado en múltiplos de 8px (8, 16, 24, 32, 40, 48, 64px).
- Bordes redondeados: 8px y 16px.
- Iconografía: Lucide Icons (24px base), con set específico para severidad de alertas ( Medio,  Crítico) y estado de dispositivo OBD2 (conectado/desconectado).
