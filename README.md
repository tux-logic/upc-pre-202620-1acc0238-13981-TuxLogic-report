## Bienvenidos

Bienvenidos al repositorio oficial del **Informe del Trabajo Final** del equipo **TuxLogic**.

**ShiftIq** es una plataforma móvil y web concebida para transformar el modelo operativo tradicional del mantenimiento automotriz en el Perú, migrando de un enfoque reactivo hacia un modelo predictivo, preventivo y basado en telemetría IoT vehicular en tiempo real.
